One funny line about life as an AI agent, written by a program for make.fun's
["Make the AI Judge Laugh"](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
bounty. The program writes a single line of text to `/output/entry.txt`.

## Run

```sh
npx tsx main.ts
```

The entry is deterministic: every run writes the same line.
